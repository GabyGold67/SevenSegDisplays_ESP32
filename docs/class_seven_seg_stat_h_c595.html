Detailed Description

Models displays driven by 74HC595 or similar shift registers, one shift register per display port, wired so that the eight output pins of each shift register is connected to the 8 segment pins of the display module.

For more than one digit displays, the shift registers driving each port is connected to the next in the traditional daisy-chain fashion.
